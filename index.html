Full-Stack Application

FinTrack

A production-deployed personal finance application built with Java, Spring Boot, React, TypeScript, and MySQL. FinTrack provides secure, user-scoped transaction, budget, and category management with financial analytics and a responsive dashboard, deployed across Vercel and Railway.

  • Short-lived JWTs with rotating refresh-token sessions
  • Transaction CRUD, filtering, sorting, and pagination
  • Monthly budgets and custom categories with spending analytics
  • Profile photos via Cloudinary and uptime monitoring
  • 2,300+ automated tests, including MySQL integration tests

Test Automation / QA Engineering

FinTrack Selenium Automation Suite

A standalone end-to-end regression suite for the deployed FinTrack application, built with Java, Selenium WebDriver, JUnit 5, and Maven. Page objects, explicit waits, and run-specific test data keep it reliable against production, and read-only checks run automatically in GitHub Actions.

  • 16 browser test classes covering authentication, transactions, budgets, categories, and the dashboard
  • Page Object Model with explicit-wait synchronization
  • Read-only and mutating tests with run-specific data and cleanup
  • Headed and headless Chrome, plus framework unit tests
  • GitHub Actions, CodeQL, and automatic failure evidence
Java Selenium JUnit 5 Maven GitHub Actions

Backend REST API

Job Search Manager API

A production-deployed REST API built with FastAPI, SQLAlchemy, and MySQL for tracking a job search: companies, applications, interviews, and follow-up tasks. Each user’s records are isolated behind JWT authentication, schema changes run through Alembic migrations, and every pull request runs the test suite against MySQL before deploying to Railway.

  • JWT authentication, Argon2 password hashing, and per-user data isolation
  • Companies, applications, interviews, and follow-up tasks
  • Job-search summary with status and outcome counts
  • Search, filtering, sorting, and pagination
  • 328 automated tests with 99% coverage, run against MySQL
Python FastAPI MySQL SQLAlchemy Alembic JWT Pytest
